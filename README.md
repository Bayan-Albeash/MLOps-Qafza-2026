# MLOps Engineering Training Program

## Qafza Tech — 12-Week Applied Program

Welcome to my **MLOps Engineering Training** journey with **Qafza Tech**.

This repository contains my work, assignments, and practical projects throughout the program, with the **Olist Brazilian E-Commerce Dataset** as the main case study.

---

## About Qafza Tech

**Qafza Tech** is a data and AI academy focused on practical, job-ready skills in machine learning, data science, and MLOps.

The program provides hands-on experience with real-world tools and workflows, progressing from local development to production-ready machine learning systems.

---

## Program Overview

The **12-week MLOps Engineering Program** focuses on building an end-to-end machine learning system.

The main challenge is to build a system capable of predicting whether an e-commerce order will be **delivered on time or late**, using the Olist Brazilian E-Commerce Dataset.

## Capstone Project

The final goal of the program is to integrate the different components into a complete **End-to-End ML System**.

### Planned Components

| Component               | Description                                 |
